## 本地查看

在 frontend 中执行 `npm run preview:studio`，打开 http://127.0.0.1:5181/ 。该脚本只在本地回环地址提供示例文章和 iframe 插件，并标记“本地演示”；可用 demo / demo 演示登录；上传和内容写入不可用，不修改真实数据库或插件存储。示例接口不会进入生产构建。

真实后端模式：`npm run dev -- --host 127.0.0.1 --port 5180`，默认代理到 8090；可用环境变量 `BLOG_DEV_BACKEND` 指定实际本地后端。不要把演示模式视为真实后端联调完成。

## 视觉与兼容性

样式限定在 `.studio-shell` 下，不覆盖历史插件的设计变量。旧 sidebar 组件与快照实现仍保留，但新主站不挂载缩略预览或隐藏插件实例。主站构建只附带固定首页使用的 SVG，不自动构建或安装插件。
