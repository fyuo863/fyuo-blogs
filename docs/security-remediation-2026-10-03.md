## 已提交的本地修复

- MCP 每次请求验证 API key，绑定会话指纹；撤销检查、空闲回收、128 会话上限和跨身份测试。
- 普通 JSON 1 MiB、登录 4 KiB、图片请求 9 MiB/文件 8 MiB、插件请求 33 MiB；图片尺寸、真实解码及扩展名一致性校验。
- 登录账户 10 次/15 分钟；Nginx 按真实连接 IP 限速，API/MCP/上传并发限制。后端不信任外部 X-Forwarded-For。
- release 环境拒绝短密钥、数据库密码复用和已知占位值；开发环境缺省密钥随机生成。
- 登录会话存 PostgreSQL；退出撤销，逐请求重新检查账户角色与密码指纹。升级会使旧登录失效，API key 不受影响。
- HSTS、nosniff、Referrer-Policy、frame-ancestors、敏感路径拒绝；完整资源 CSP 仍为 Report-Only。
- 后端/MCP 非 root、只读根目录、能力剥离、资源及日志限制；现有卷仅迁移所有者，不改插件内容或数据库记录。此项尚未完成容器运行验证。
- 发布工作流必须先通过 CI；补上 MCP 安全回归。
- 修复空站侧栏管理按钮被 inert 隐藏、侧栏链接点击；兼容性测试隔离外部字体网络，并等待预览首次加载再模拟同步失败。
