# 侧栏画面快照

侧栏不再为每个栏目创建 iframe 或运行第二份插件。只运行主区域当前选中的插件。

- 从主阅读区域当前可见视野生成缩略图，包括滚动位置。
- 全屏 Canvas 页面直接复制已有画布，输出不超过 320×225 像素；普通 DOM 页面使用 modern-screenshot 生成同尺寸快照，捕获不执行克隆内容中的脚本。
- 展开时约每 2 秒更新一次，收起时约每 5 秒更新一次。滚动和窗口尺寸变化会安排更新，页面隐藏时不截图。任务串行，不堆积。
- 未访问栏目先显示名称占位；访问后保留最近快照。最多保留 12 张，按插件 id 和发布版本区分，只保存在当前页面内存，刷新后重新生成，不上传服务器。
- 跨域资源、受污染画布或旧 sandbox iframe 无法可靠截图时，保留旧快照或占位，不放宽 iframe 沙箱、不申请屏幕共享权限。DOM 重建不是浏览器合成器截图，复杂 WebGL、视频或特殊 CSS 的效果可能有差异。
- 管理面板位于截图区域之外，desk 不截图；输入框、textarea、select 及 data-no-snapshot 元素不复制。

这是主站外壳修改，部署主站后生效；不需要重新上传既有页面插件。保留旧 __plugin_preview 路由的兼容性，但侧栏不再访问它。
